# Лаборатори №1: Playwright UI Автомат Тест

## Гүйцэтгэсэн ажлын товч
Энэхүү лабораторийн ажлаар Playwright хэрэгслийг ашиглан SauceDemo (https://www.saucedemo.com) веб сайтад дараах 3 функционал тестийг бичиж гүйцэтгэлээ:
1. Хэрэглэгч зөв мэдээллээр амжилттай нэвтрэх болон гарах тест.
2. Буруу нууц үг ашиглан нэвтрэх үед алдааны мэдээлэл харуулж буйг шалгах сөрөг тест.
3. Системд нэвтэрсний дараа бараа сагсанд нэмэх үйлдэл.

## Playwright ба Selenium харьцуулалт болон ажиглалт
Энэхүү лабораториор Playwright ашиглахад Selenium-ээс хэд хэдэн тодорхой давуу тал ажиглагдлаа. 
Нэгдүгээрт, Playwright-ийн **Auto-wait** функц нь элементийг бэлэн болтол автоматаар хүлээдэг тул Selenium шиг explicit wait бичих шаардлагагүй, тест илүү найдвартай ажиллаж байна. 
Хуудасны элементийг олоход XPath ашиглахын оронд хэрэглэгчийн харж буйтай ижил `getByRole`, `getByPlaceholder` зэрэг харааны locator-уудыг ашиглах нь кодыг уншихад илүү хялбар болгож байна.
Мөн **Codegen** хэрэгсэл нь тестийн үйлдлийг бичиж автоматаар код болгон хурдан эхлүүлэхэд маш их тустай байв. 
Ялангуяа **Trace Viewer** нь тестийн алхам бүрийн DOM snapshot болон видеог харуулдаг тул алдааг илрүүлж, дебаг хийхэд Selenium-ээс хавьгүй илүү хялбар санагдлаа.

## Яагаад XPath-аас зайлсхийх хэрэгтэй вэ?
XPath нь вебийн DOM бүтэц бага зэрэг өөрчлөгдөхөд л эвдэрч (fragile), тест унах аюултай байдаг. Учир нь веб дизайны код шинэчлэгдэх бүрд маш амархан өөрчлөгддөг. Иймд Playwright-ийн зөвлөдөг `getByRole`, `getByLabel` зэрэг хэрэглэгчид харагдах утгад суурилсан locator-уудыг ашиглах нь тестийг илүү уян хатан, найдвартай (robust) болгодог.
